### 3.16 S4 — the reconciliation pass, measured against predicted

**Not a build-order step**, and nothing shipped. §5's table is what gets built; this is a pass over
what the eleven documents *say* about what was built, taken because the documents were written at
P1–P9 before a single line existed and steps 1–3b have since produced 166 decisions against them.

**The repo already had the rule and had never applied it:** *when two documents disagree the later
phase wins, and within a phase a measurement beats a prediction* (`CLAUDE.md`; §7). Applying it
systematically is all this step is. The register of what was marked is **§6.1**; these six entries
are only the decisions the marking forced.

**The headline is not any single stale sentence. It is that one sweep left seven survivors.**
`e4f5d91` implemented D-110 in the two places D-110 names and in none of the six places the rule was
restated — which is the failure mode the three-surface split (§0) exists to prevent and does not,
because a rule restated in a *fourth* place is invisible to a sweep aimed at the first two.

**D-167 · D-110's sweep is completed, and D-109's open gate line is un-ticked**
— **Decision.** The six surviving restatements of *"an axe allowance carries an upstream issue
number"* are corrected to D-110's rule — *names where the gap is argued, in our own documents* — in
`CLAUDE.md`, `definition-of-done.md` rule 2.2 and §3.0, `testing.md` §4.1, `component-blueprint.md`
§9.3 and `prior-art.md` §10.1 row F. Separately, `zag-solid-adapter.md` §6.5's `✅ A1 filed
upstream` becomes `⬜ OPEN`, and `definition-of-done.md` §3.1 step 2 stops listing *"A1 filed"*
among a discharged step's proofs.
— **Rejected.** *Leave them; D-110 governs and the ledger is authoritative* — a reader who opens
`CLAUDE.md` does not open the ledger, and `CLAUDE.md` is the file read on every task. That is the
whole argument for the operative index existing, and it fails if the index is the stale copy.
*Delete the restatements instead of correcting them* — five of the six are load-bearing sentences in
a rule table; the requirement is right, only its object was wrong.
— **Effect.** The instruction a future session reads now matches the one the author gave. Before
this, a session opening `CLAUDE.md` at step 5 would have gone looking for an issue number to cite
per Dialog allowance, found none, and either invented a filing or blocked — the exact failure
D-110's *Rejected* column predicted (*"step 5's Dialog would fail on the register's own rule rather
than on anything about Dialog"*). The `⬜` matters for the same reason: a `✅` beside A1 is this
document marking satisfied the one line D-109 required kept open, which D-109 explicitly listed as
a rejected alternative.
— **Settled.** S4, 2026-08-10, by grep over the corpus for `upstream issue|issue number|A1 filed`.
— **Reasoning.** D-109; D-110; `testing.md` §4.2 property 2.

**D-169 · The enforcement census carries its procedure, because its figures did not reproduce**
— **Decision.** §7b gains the runnable four-command form of its own census, including the one
exclusion — `check:context-sessions`, which a literal grep counts and which appears in the corpus
exactly once, in the sentence explaining that it is not a check.
— **Rejected.** *Change the figures to 48/26 and count the name* — the census counts artefacts a
reader could mistake for enforcement, and a name introduced in order to be ruled out is not one.
*Rename or remove the mention so the grep is clean* — the sentence is the reason the transcript half
is a flag rather than a script, which is a thing worth explaining.
— **Effect.** **47 / 22 / 25 / 0, unmoved across three commits.** The number was never wrong; the
procedure that produces it was unstated, so the next person to run it gets 48 and cannot tell
whether something was added or whether they ran it wrong. A census whose method is not reproducible
is an assertion.
— **Settled.** S4, 2026-08-10, by running the documented form and reproducing 47/22/25/0 exactly.
— **Reasoning.** `definition-of-done.md` §7b.

**D-170 · The dev stylesheet reaches the tarball, and the guard is a §8 row rather than a check**
— **Decision.** Record it as **§8.3c row S4-A**, with the measurement, and fix `turbo.json`'s
*"never published"* comment. **No script is written now.**
— **Rejected.** *Write the tarball assertion into `check:exports` today* — the pass's terms are no
new `check:*`, and more to the point nothing is publishable at `0.0.0`, so a check written now
guards nothing and joins the twenty-five §7b already counts. *Drop `styles.css` from `files`* — the
directory is the export surface and carving one generated file out of it is a build change this pass
has no mandate for, made without the release path in view. *Say nothing, since CI is clean* — the
whole category §7b exists for.
— **Effect.** Measured 2026-08-10: after `pnpm cssgen`, `npm pack` on
`@chakra-ui-solid/styled-system` includes `styled-system/styles.css` at **319 KB**. `files:
["styled-system"]` is a directory and `check:exports` tests `files` entries for a `.css` *suffix*.
The release path escapes it **only by task ordering** — `codegen` runs `panda codegen --clean`,
which deletes the sheet, and `build` depends on `codegen`, never on `cssgen`. So the rule
`CLAUDE.md` §0 states as absolute holds today by accident, and a publish from any working tree where
someone ran `pnpm cssgen` ships the CSS with a green build. Both halves of §0's second boundary —
*no CSS in the package* — currently rest on a Turbo edge nobody wrote down as load-bearing.
— **Settled.** S4, 2026-08-10, by `npm pack --dry-run --json` and by running `codegen` and watching
the file disappear. Gate before first publish.
— **Reasoning.** `plan.md` §4.4; `CLAUDE.md` §0; `definition-of-done.md` §8.3c.

**D-171 · A citation resolver is run once and not promoted to a `check:*`**

`zag-solid-adapter.md` §7.3's `` `legal.md` §9.2 `` — pointing into a document whose headings stop

— **Settled.** S4, 2026-08-10.
— **Reasoning.** `testing/8.01-doc-index.md` blind spot 2; `definition-of-done.md` §8.3c.

— **Rejected.** *Mark every claim inline* — 180 KB across the two, where the honest ratio is *nearly

(*"a Root calls `useMachine` bare"*, *"ships / B7"*), which is the grammar of a report, and

— **Effect.** The two largest documents in the corpus stop reading as status. Concretely:
`roadmap.md` §4 has **115 rows and exactly one of them exists** (`Box`), and nothing in the table
said so. The banner also routes the reader to the ledger for the rows that *have* since been
measured — D-140, D-151, D-133 — none of which were written back into §4.

— **Reasoning.** `decisions.md` §6.1; D-131 (a hazard note is marked, never deleted).
