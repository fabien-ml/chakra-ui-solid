## Usage

The `AbsoluteCenter` component uses the `position: absolute` strategy to center its child element
relative to its parent.

> The parent element must have `position: relative` for proper positioning.

```tsx
import { AbsoluteCenter } from "@chakra-ui-solid/components";
```

```tsx
<Box position="relative" h="100px">
  <AbsoluteCenter>Centered Content</AbsoluteCenter>
</Box>
```

## Props

`AbsoluteCenter` is a single factory call with one variant, `axis`, and no props of its own beyond
it — so there is no generated table here. It takes the whole style-prop surface, plus `as` and
`render`, like every component in this tier.
