## Usage

```tsx
import { Alert } from "chakra-ui-solid";
```

```tsx
<Alert.Root>
  <Alert.Indicator />
  <Alert.Content>
    <Alert.Title />
    <Alert.Description />
  </Alert.Content>
</Alert.Root>
```

If you prefer a closed component composition, check out the [snippet below](#closed-component).
