## Usage

```tsx
import { Blockquote } from "chakra-ui-solid";
```

```tsx
<Blockquote.Root>
  <Blockquote.Content cite="https://" />
  <Blockquote.Caption>
    <cite>Uzumaki Naruto</cite>
  </Blockquote.Caption>
</Blockquote.Root>
```

If you prefer a closed component composition, check out the [snippet below](#closed-component).
