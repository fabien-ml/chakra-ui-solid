# Box

The foundational styled primitive. It takes the whole style-prop vocabulary — `p`, `bg`, `mt`,
`_hover`, `colorPalette` — carries no recipe of its own, and renders a `div` unless you tell it
otherwise.

<Example name="box-basic" />

Everything a component does with style props, Box does with nothing else in the way, which makes
it the shortest path to finding out whether your Panda setup is wired correctly.

**Source:** `packages/components/src/box` · **Recipe:** none · **Machine:** none ·
[Chakra's Box](https://chakra-ui.com/docs/components/box)

## Usage

```tsx
import { Box } from "@chakra-ui-solid/components";
```

Box is a single element. There is no anatomy to nest and no part components — the whole API is one
component and its props.

```tsx
<Box />
```

## Examples

### Changing the element

`as` renders a different element. It stays a loose `ValidComponent` rather than a generic that
re-types props from the element — deliberately, because the deep conditional types that would buy
you `href` on `as="a"` also wreck editor completions across the whole library.

<Example name="box-as" />

### The render prop

Polymorphism beyond `as` is the `render` prop, on Box and on every part of every component. It is
a **function** that receives the computed props and returns the element — never a JSX element, and
never `asChild`. A Solid JSX element is an already-constructed node by the time it reaches us and
there is no `cloneElement`, so accepting one could only mean dropping every prop that was computed
for it.

<Example name="box-render" />

That cast is real and it is the deliberate trade, not a rough edge waiting to be filed off. `as`
stays a loose `ValidComponent` rather than a generic that re-types props from the element, because
the deep conditional types that would buy you `href` on `as="a"` also wreck editor completions
across every component in the library. The measured consequence is narrow and worth stating
plainly: Box types its element props against `HTMLElement`, and Solid's `Ref<HTMLElement>` is not
assignable to `Ref<HTMLAnchorElement>` — so a `render` target that is a **host element narrower
than `HTMLElement`** needs a cast. Elements whose interface *is* `HTMLElement` — `section`,
`article`, `span`, `mark` and their neighbours — need none, and neither does a component that
accepts `JSX.HTMLAttributes<HTMLElement>`.

## Style props take literals

The one thing about Box that is not Chakra's:

```tsx
<Box w="64" />              // ✅ a literal — Panda reads it out of this file
<Box w={width()} />         // ❌ a class whose rule was never generated: no error, no style
<Box w="var(--w)" style={{ "--w": width() }} />   // ✅ the escape hatch
```

Panda extracts styles by scanning source **text** at build time, so a value it cannot read at the
call site produces a class name with no rule behind it. Nothing errors, nothing warns, and a test
asserting the class name passes. The route for a genuinely dynamic value is a CSS custom property
written through the inline `style` attribute and read by a static class — which is an ordinary
reactive write in Solid, not a concession.
