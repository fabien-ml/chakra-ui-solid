## Usage

```tsx
import { Checkmark } from "chakra-ui-solid";
```

```tsx
<Checkmark checked />
```

> `Checkmark` is the mark, not the control. It has no input behind it and nothing to click — a
> `Checkbox` supplies the state and the label, and this is what it draws inside.
