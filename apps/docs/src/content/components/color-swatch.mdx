## Usage

```tsx
import { ColorSwatch } from "chakra-ui-solid";
```

```tsx
<ColorSwatch value="#bada55" />
```

> `value` is required. The colour and the checkerboard behind it share one `background` shorthand,
> so a swatch with nothing to paint loses both and renders as an empty box.
