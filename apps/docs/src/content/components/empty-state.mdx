## Usage

```tsx
import { EmptyState } from "chakra-ui-solid";
```

```tsx
<EmptyState.Root>
  <EmptyState.Content>
    <EmptyState.Indicator />
    <EmptyState.Title />
    <EmptyState.Description />
  </EmptyState.Content>
</EmptyState.Root>
```

If you prefer a closed component composition, check out the [snippet below](#closed-component).
