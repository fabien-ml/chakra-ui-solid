## Usage

Float requires a parent element with `position: relative` style applied.

```tsx
import { Box, Float } from "chakra-ui-solid";
```

```tsx
<Box position="relative">
  <Float>
    <div />
  </Float>
</Box>
```

## Props

<PropsTable component="float" />

`placement`, `offset`, `offsetX` and `offsetY` are inherited rather than declared: they are
Panda's own `float` pattern's properties, reused whole because that pattern computes exactly what
Chakra's Float computes — the same nine placements, the same `offsetX ?? offset` fallback, the
same defaults.
