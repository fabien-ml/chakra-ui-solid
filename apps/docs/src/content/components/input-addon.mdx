## Usage

```tsx
import { InputAddon } from "chakra-ui-solid";
```

```tsx
<Group attached>
  <InputAddon>https://</InputAddon>
  <Input placeholder="yoursite.com" />
</Group>
```

> An addon takes width of its own, and it is the attached [Group](/docs/components/group) around it
> that collapses the seam and rounds only the outer corners.
> [Input Group](/docs/components/input-group) is the shortcut that does both for you.

## Examples

### Sizes

Use the `size` prop to change the size of the addon. It is not inherited from the control, so give
the addon and the input the same value or the two steps will not line up.

<Example name="input-addon-with-sizes" />

### Variants

Use the `variant` prop to change the visual style of the addon, mirroring the input's own three.
