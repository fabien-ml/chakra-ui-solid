## Usage

```tsx
import { InputGroup } from "chakra-ui-solid";
```

```tsx
<InputGroup startElement={<SearchIcon />}>
  <Input />
</InputGroup>
```

> An **element** is drawn on top of the control and takes no width of its own — the control is
> padded so its text stays clear of it. An **addon** is a neighbour: it takes width, and the group
> collapses the seam between the two so they read as one control.

## Examples

### Element

Use the `startElement` and `endElement` props to draw an icon, a unit or a shortcut hint inside the
control. Each renders an [Input Element](/docs/components/input-element), and the control takes the
padding that clears it.

<Example name="input-group-with-elements" />

### Addon

Use the `startAddon` and `endAddon` props to weld a label to either side of the control. Each
renders an [Input Addon](/docs/components/input-addon), and the group attaches itself as soon as one
is present, so the row shares a single outline.

<Example name="input-group-with-addon" />

### Sizes

An addon does not inherit the control's size. Give it the same value through `startAddonProps` or
`endAddonProps`, or the two steps will not line up.

<Example name="input-group-with-sizes" />

### Offset

Use the `startOffset` and `endOffset` props to give some of the padding back. The control is padded
by its own height less the offset, so a narrow element leaves less dead space before the text.

<Example name="input-group-with-offset" />
