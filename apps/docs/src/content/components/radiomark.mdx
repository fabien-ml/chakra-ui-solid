## Usage

```tsx
import { Radiomark } from "chakra-ui-solid";
```

```tsx
<Radiomark checked />
```

> `Radiomark` is the mark, not the control. It has no input behind it and nothing to click — a
> `RadioGroup` supplies the state and the label, and this is what it draws beside them.
