## Usage

```tsx
import { Skeleton, SkeletonCircle, SkeletonText } from "chakra-ui-solid";
```

```tsx
<Stack gap="6" maxW="xs">
  <HStack width="full">
    <SkeletonCircle size="10" />
    <SkeletonText noOfLines={2} />
  </HStack>
  <Skeleton height="200px" />
</Stack>
```

The first one uses `render` to put the placeholder's styles onto the badge itself, rather than
around it. That is what the React version's `asChild` does, spelled as a function because Solid
hands a component computed props instead of an element to clone.
