## Usage

```tsx
import { VisuallyHidden } from "@chakra-ui-solid/components";
```

```tsx
<VisuallyHidden>Hidden content</VisuallyHidden>
```

## Examples

### Input

Using the `render` prop, you can render the `VisuallyHidden` styles onto an element of your own.

<Example name="visually-hidden-with-input" />

`render` is this library's answer to `asChild`, and it is a **function** that receives the computed
props rather than a child element — for the same reason `Stack`'s separator is a component. See
[Box](/docs/components/box#render) for the whole of it.
