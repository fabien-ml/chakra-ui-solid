## Usage

By default, `Wrap` applies `display: flex`, `flex-wrap: wrap`, and `gap: 8px` to its children.

```tsx
import { Wrap, WrapItem } from "chakra-ui-solid";
```

```tsx
<Wrap>
  <div />
  <div />
</Wrap>
```

## Examples
