# A landed divergence is recorded; the docs page stays silent

When a component observably differs from Chakra, the difference is recorded as a decision in `docs/adr/`. The component's docs page does not mention it: docs content stays 1:1 with upstream (see [0009](0009-docs-content-1-to-1-with-upstream.md)). The page of a component whose behaviour we alone add or drop still documents what exists.
