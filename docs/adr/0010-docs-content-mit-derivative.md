# Docs prose is MIT, so docs copy pages and owe one notice row

Chakra's docs live in the same repository as its code under a single MIT grant at the repo root (measured: one `LICENSE`, none under `apps/www`, `"license": "MIT"` on the root `package.json`). MIT permits copying outright; its one condition is that the notice travels with the copy.

So the docs content copies Chakra's pages (structure, order, examples, prose), and the obligation is one directory-scoped row in the root `NOTICE.md` covering the whole content directory, not one row or `@license` header per page: the content tier is one derivative, not 111.

What copying prose does not change: generated tables stay generated, token pages stay rendered from the installed preset, no screenshot of chakra-ui.com appears anywhere, and trademark is a separate control ([0002](0002-branding-and-trademark.md)).
