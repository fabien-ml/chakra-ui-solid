# The dynamic-value contract is the loudest docs page

Silent unstyling (a class whose CSS was never generated renders nothing, with no error) is this project's central hazard, and the page that explains how to avoid it is the most prominent in the docs, not a footnote in theming. The responsive opt-in sits on the same page as the silent-unstyling warning, not in a theming appendix: a reader hits the warning and its remedy together. The routes themselves are in [0026](0026-dynamic-value-routes.md).
