# Files carried over from hope-ui keep a provenance note, not a notice row

hope-ui is the same author under the same MIT licence, so carrying a file over creates no third-party obligation and no `NOTICE.md` row. Each carried file still gets a provenance note in its header (source path plus commit), not as a legal requirement but so the lineage stays legible and the next reader can find the commit that argued the design.

Carried files fork on copy: no sync obligation in either direction.

Contrast a derivative of someone else's MIT code, which needs an `@license` header naming the upstream file plus rows in the root and package `NOTICE.md` ([0045](0045-notice-per-package.md)).
