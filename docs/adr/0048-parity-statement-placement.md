# Where the parity sentence and the Panda prerequisite appear

The parity sentence ("as close to Chakra v3 parity as is achievable without runtime CSS-in-JS") appears verbatim in four places: the README's first paragraph, the docs home, the install page (as the Panda prerequisite line, its operative half) and the migration page's lede. It is not repeated on component, styling or props pages. A sentence a reader has seen four times and sees a fifth stops being read, which would cost the pages where it matters most.

The prerequisite line ("Requires Panda CSS in your build. Not optional, this library publishes no CSS.") appears in three places with its wording unchanged: the README's first line, the docs home and the install page.
